# AdmissionGPT

AdmissionGPT is an AI-powered admission guidance system designed for Government Model Engineering College (MEC).

## Features

- Branch preference prediction using Machine Learning
- Historical cutoff analysis
- FAQ support
- Streamlit-based chatbot interface

## Technologies Used

- Python
- Pandas
- Scikit-Learn
- Streamlit
- OpenRouter (future integration)

## Project Structure

- ML Branch Prediction
- Cutoff Analysis Engine
- FAQ Engine
- Chat Interface

## Future Enhancements

- Generative AI Integration
- Voice Support
- Multi-college Recommendation
- Admission Trend Forecasting
